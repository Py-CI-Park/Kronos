# V6 연구 라이브러리·실시간 학습·평가 비교 UX 개선 결과

- 작성일: 2026-08-06 KST
- 개발선: `codex/v1.28.0-dev-ux-unification`
- 기준 버전: `v1.28.0-dev`
- 범위: 연구 라이브러리, run 상세, 실시간 학습, 평가·비교, 태블릿 탐색
- 운영 경계: 읽기 전용 연구 화면. 수익성·실거래 준비 완료를 주장하지 않음

## 1. 결론

사용자 지적은 타당했다. 기존 화면은 데이터가 없는 것이 아니라 데이터와 설명을 연결하는 방식이 부족했다. 연구 라이브러리는 98개 run을 메타데이터 행으로 한꺼번에 노출했고, 실시간 학습의 최근 행동은 10개 카드뿐이었으며, 평가의 1~9 단계는 정적 목록이었다. 비교 차트는 2열·300px 고정 레이아웃과 긴 범례 때문에 축과 범례가 겹쳤다.

이번 변경은 가짜 지표를 추가하지 않고 이미 기록된 evidence·telemetry만 더 잘 읽게 만든다. telemetry가 없으면 차트를 합성하지 않고 `TELEMETRY MISSING`으로 표시한다.

## 2. 원인과 조치

| 문제 | 확인된 원인 | 조치 | 검증 결과 |
|---|---|---|---|

| 상세 결과 시각화 없음 | run detail API와 telemetry API가 연결되지 않음 | detail에서 telemetry를 함께 조회해 reward·equity·drawdown·loss·exploration·action 표시 | `stom_orderbook_dqn_smoke` 240 point·9 artifacts 표시 |
| telemetry 없는 결과를 이해하기 어려움 | 404가 결과 부재 이유로 설명되지 않음 | `TELEMETRY MISSING`과 실제 artifact 크기 분포 표시 | 독립 QA의 `rl_discovery`에서 404·0 artifacts를 안전하게 분리 표시. 별도 직접 점검의 `type1-close-20260803-005`는 404·3 artifacts 표시 |
| 최근 행동이 카드뿐임 | 시간/step 모델과 행동 분포 모델 부재 | 시간대별 행동 산점도, 확대 슬라이더, BUY/SELL/HOLD 분포, 최근 12건 타임라인 추가 | 표본 224 events, SELL 66·BUY 52·HOLD 106 확인 |
| 평가 1~9가 클릭되지 않음 | 정적 `<li>` 목록 | 9개 접근 가능한 버튼으로 변경, 단계별 입력·출력·통과조건 패널 연결 | 비용 7단계 클릭 후 세부 정보 변경 확인 |
| 비교 차트가 작고 겹침 | 2열·300px, 범례/축 여백 부족 | 단일 열·430px, 상단 범례, 하단 확대 슬라이더, 축 레이블 충돌 방지 | 데스크톱 브라우저에서 범례/축/슬라이더 분리 확인 |
| 태블릿에서 탭 클릭 불능 | 과거 전역 `.sidebar` CSS가 V6에도 `translateX(-100%)` 적용 | V6 전용 sidebar에서 `transform:none`, `width:auto`로 격리 | 768px에서 평가 탭 URL 전환 및 9개 버튼 확인 |

## 3. 화면별 현재 기능

| 페이지 | 추가된 기능 | 사용자가 확인할 것 | 해석 제한 |
|---|---|---|---|
| 연구 라이브러리 | 페이지 이동, 판정 분포, lane 분포, 결과 근거 meter | `연구 라이브러리`에서 이전/다음, 검색, `결과 근거 n/4` | 근거 개수는 성능 점수가 아님 |
| Run Detail | 관측 결과 곡선, 행동 분석, artifact 크기 | telemetry가 있는 run과 없는 run 각각 확인 | artifact 크기는 품질·수익성을 뜻하지 않음 |
| 실시간 학습 | 읽는 순서, 확대 가능한 3개 성과 곡선, 시간 행동 타임라인·분포 | `HISTORICAL_SNAPSHOT`/`FOLLOWING_FILE`, action 쏠림 | reward는 수익률이 아니며 표본은 전체 파일이 아닐 수 있음 |
| 평가·비교 | 클릭 가능한 종가매매 9단계, 큰 비교 차트, 실행 범례 | 단계 클릭, 같은 lane 선택, 슬라이더 확대 | 기술 비교이며 공식 OOS 순위가 아님 |

## 7. 최종 판단

이번 변경으로 연구 결과를 찾고, 실제 telemetry가 있는지 확인하고, 학습·경제 경로·행동을 분리해 읽고, 같은 lane 두 실행을 비교하는 UX는 실사용 가능한 수준으로 개선됐다. 그러나 강화학습 종가매매 모델의 경제적 성공은 아직 증명되지 않았다. 다음 연구는 화면 추가보다 `daily_close` run의 표준 telemetry와 사전등록 OOS 반복 실험을 연결하는 작업이 우선이다.
